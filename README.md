# Green Horizon — Layer Growth Model

Installable web app (works offline after the first visit). No build step.

## Put it online (GitHub Pages)
1. New repo (e.g. `green-horizon-growth-model`) → Add file → Upload files → upload ALL files in this folder (index.html, manifest.json, sw.js, 3 icon PNGs) → Commit.
2. Settings → Pages → Deploy from a branch → `main` / root → Save.
3. Open `https://<username>.github.io/<repo>/`

## Install on your phone
- Android (Chrome): open the link → ⋮ menu → "Install app" (or "Add to Home screen").
- iPhone (Safari): open the link → Share → "Add to Home Screen".
